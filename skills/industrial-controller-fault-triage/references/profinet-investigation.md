# PROFINET 与配置控制

- K-02 / KS-002：同一设备的工程名与设备存储名需匹配；先核对站点、MAC/标签和对象。网络可见或 CPU RUN 不表示 IO 交换正常。
- K-04/K-05 / KS-003：按指令、MODE、LADDR 层级解释返回，保留有效性和覆盖范围。
- K-03 / KS-004：配置控制允许某些合法差异；启用且有对应记录与启动证据时才适用缺记录 STOP 机制。
- K-07 / KS-007：导出时间、时区和权限决定可用信息范围。

名称、IP、程序及控制记录修改是现场受控变更，由授权人员执行；Skill 提交证据和建议。统一规则通过知识检索读取，开发端索引位于 `03_知识与规则来源/统一知识_v0.7/`。
