# 五页信息结构

这是页面实施合同；五页真实界面与三种尺寸验收见 acceptance.md。沿用 V0.3 深色侧栏、浅色内容、紫色强调、卡片和表格；正式导航仅五项。原型示例业务数据、用户问题标题、顶部预览身份切换不进入成品。

## 共享 Shell

顶部：DeviceTruth、当前登录邮箱/名称、退出、返回工作台。侧栏依次为用户管理、运行与用量、知识库管理、Skill 管理、系统与审计。后台权限以 /api/admin/access 判断，退出复用 /api/auth/logout。

进入时依次恢复 /api/auth/me 和管理 access。401 转统一登录并清缓存；403 显示“无平台管理权限”；不显示伪造空列表。空间操作使用“管理目标空间”选择器，数据来自 /api/admin/workspaces，与工作台当前空间分别表达。

## 用户管理：/admin/users

| 区域 | 内容 |
| --- | --- |
| 筛选 | 邮箱/名称检索、ACTIVE/DISABLED、PLATFORM_ADMIN/NONE |
| 表格 | userId、邮箱、名称、平台角色、账号状态、创建时间、操作 |
| 开户表单 | email、displayName、initialPassword；不出现平台角色/团队选择 |
| 状态确认 | 目标账号、动作、reasonCode、停用影响提示 |
| 成功 | 回读列表；开户返回 userId/个人空间 ID；不显示密码 |
| 冲突 | LAST_PLATFORM_ADMIN/状态版本冲突说明，保留非秘密输入并刷新 |

密码不存浏览器草稿、URL 或日志，提交结束/关闭清空。停用说明区分账号停用、移除成员和退出，说明恢复不自动重放任务。平台角色只读，维护说明提供可信入口的使用范围。

## 运行与用量：/admin/runs

页内分“运行记录”“用量统计”“额度与占用”，不新增侧栏模块。

| 区域 | 内容 |
| --- | --- |
| 筛选 | 时间窗、明确时区、workspaceId、初始/当前 actor、状态、稳定错误码；无问题文本搜索 |
| 指标 | Run 总数、状态分布、模型尝试数、已报告 token、覆盖率；金额按币种/模型桶 |
| 表格 | Run ID、空间 ID、actor UUID、状态、时间、活跃耗时、模型、失败码、用量状态 |
| 详情抽屉 | 生命周期、白名单模型/工具尝试及计数；无答案/问题/来源正文 |
| 额度 | 归属、资源类型、上限、周期、已用/占用/剩余、更新时间、对账/就绪状态 |

WAITING 显示“等待补答”；缺时长/费用显示未知；覆盖不足显示已报告小计。明确总历时和活跃执行时长。无“查看用户完整调查”、Prompt、原始事件或在线付费探测按钮。

## 知识库管理：/admin/knowledge

先选有 KNOWLEDGE_READ/MANAGE 的目标空间，再加载。

| 区域 | 内容 |
| --- | --- |
| 筛选/表格 | 标题、领域/型号、版本、来源性质、处理状态、入库状态、可用状态、材料范围、发布时间 |
| 上传 | Markdown 文件、标题、领域、型号、版本、来源/许可标识；目标空间明确显示 |
| 元数据详情 | 来源性质、版本、章节索引、切片数、文件处理、release/发布/可用状态、稳定失败码 |
| 操作 | 导入、失败文件重试、停用、恢复；按钮按 capability/readiness/生命周期显示 |
| 状态说明 | READY 是处理成功；启用不等于许可/发布；停用保留历史引用 |

页内“导入任务”通过 /api/admin/knowledge/files 单独分页展示受理/处理中/失败任务，刷新后可继续定位；来源/许可选项取 /api/admin/knowledge/sources，无有效登记时不能提交。

不展示用户调查附件总览、原文件或正文下载。失败重试复用 fileId；成功资料改内容通过新版导入。恢复若因 release 未激活/来源条件失败，显示相应状态，不假报启用。

## Skill 管理：/admin/skills

页内“部署目录”“空间授权”。

| 区域 | 内容 |
| --- | --- |
| 部署目录 | skillId、名称/说明、加载版本、设备/任务、声明工具集 |
| 目录详情 | 受控正文、reference 清单和单篇读取；无路径 |
| 空间授权 | 目标空间、安装版本、enabled、实际工具集、管理 revision、可用性原因 |
| 开通确认 | 当前加载版本、实际工具集、目标空间、reasonCode |
| 启停确认 | 当前状态、目标状态、原因；未决 Run 时展示有界 ID 列表及阻止原因 |

目录存在/已安装/启用/版本匹配分别表示。相关 Run 的完成/取消走原产品授权流程，本页不以平台身份代取消用户任务。无 ZIP 上传、编辑、删除、热升级。

## 系统与审计：/admin/system

页内“依赖状态”“管理审计”“运维说明”。

| 区域 | 内容 |
| --- | --- |
| 依赖 | 应用、PG、worker、队列、模型配置与近期调用；UP/DOWN/DEGRADED/UNKNOWN、时间、证据范围、稳定原因码 |
| 审计筛选 | 时间窗、actor、动作、目标 ID、结果、requestId |
| 审计表 | 时间、真实操作者、对象类型/ID/空间、动作、结果、原因码、关联 ID |
| 运维 | 权限初始化、配置/HTTPS、迁移、备份恢复、账号/配额/导入故障步骤 |

不显示密钥、Session、SMTP 地址/异常、连接串、服务器路径或 SQL；健康页不自动消耗模型费用。

## 全页状态与交互

- 加载/空/失败/无权/提交中/版本冲突/接入未就绪分别展示；空统计只有完整覆盖下才能显示真实零。
- 写前明确目标与影响，确认框支持 Escape、焦点约束与关闭后焦点回归；提交中防重复，失败可重试但不得擅自换幂等键或 expectedVersion。
- 筛选变化清游标；账号/目标空间变化取消旧请求并递增 generation，清详情和草稿，拒绝晚到结果。
- 明确全局运营统计与当前目标空间管理的区别；空间未选择不自动落入管理员个人空间。
- 1600×1000、1366×768、390×844 验证：正文可读、窄屏侧栏折叠、表格局部滚动，页面整体不横溢，键盘可达。
- UI 不根据未实现接口硬编码成功或演示 KPI；开发协议替身显式标记，与产品真实接口验收分开。
