# Proposal

## Why

规程指导需要独立的材料适用性、前提确认和恢复能力，不应阻塞普通答案审核简化交付。用户同意本轮收尾时从improve-evidence-aware-answer-guard拆出；原需求与未验收事实完整保留。

## What Changes

- 迁入原Guard任务3.1–3.3：规程版本、对象/配置/作业适用性，人员与现场前提确认，以及条件变化失效/重启恢复。
- 迁入对应前端规程/前提交互、真实合法材料验收及工作台消费后的联合验收。
- 仍保持工具只读，不把模拟规程、授权发布或空间角色当作现场执行资格。

## Capabilities

### New Capabilities
- `procedure-grounded-guidance`：规程支持的查阅/指导和前提确认。

### Modified Capabilities
无。

## Impact

独立后续变更，尚未实施或验收。不阻塞当前Guard整体审核收尾；依赖已有授权材料/正式输入快照以及工作台第六组实际消费。
