# 维护证据与验收

| 项目 | 观察条件与来源 | 反证/充分性要求 |
|---|---|---|
| 胎压 | 轮位、冷胎/静置、标签、量具、单位和更新时间 | 热胎/旧显示不可直接比冷胎目标；稳定窗口不排除永久慢漏 |
| TPMS | 闪烁形态、实际压力、传感器收发和告警 | 闪烁支持系统异常，不唯一证明硬件传感器坏 |
| 轮胎 | 四轮数值、规格、方向性、里程与换位记录 | 不可换位的规格不能套建议；换位后胎纹数值应守恒 |
| 制动液 | 投运/上次检查日期、适用周期、检测结果 | 到期只说明需检查；不自造通用更换阈值 |
| 制动异响 | 性能变化、警报、环境与实际检查 | 无检查回执不能说排除性能隐患 |
| 滤芯/HVAC | 地区、上次日期、实物和同风挡/环境测量 | 异味改善不等于全部制冷系统修好 |
| 雨刮 | 耗材、污染、机构、喷淋刮拭的实际结果 | 待办清单不是验收，需记录样本与通过/失败 |

单位换算应明确：1bar=100kPa；必要时保留原单位与标准值。目标由该车标签/适用文件给出，不在Skill中固定一个所有车辆共用的胎压。

SRC03明确列有中国地区滤芯周期例外；不同网页若表述不同，保留具体章节与版本，不能只因中文路径就认定市场适用。实际维护取决于使用条件，检查与更换分别判断。
