# 供电、召回与健康的区分

| 线索 | 需要的区别性证据 | 不足以推出 |
|---|---|---|
| 无法READY/APP离线 | 实际低压测量、额定与条件、钥匙/访问状态 | APP旧时间不证明电池损坏 |
| ICCU通报/低压告警 | 市场、生产范围、单车适用性、告警与授权检测 | 车型在公开范围不等于VIN命中或本次ICCU坏 |
| 做过旧措施 | 旧/新campaign、实际执行日期、模块版本与新回执 | 旧完工不等于新方案完成；无未修召回不等于无故障 |
| 热管理提示 | 原始消息、实际温度、环境与服务结果 | 提示不唯一定位泵、冷媒或传感器 |
| 续航下降 | SOC、能耗、条件与认可容量方法 | 表显百分比差不等于容量衰退百分比 |
| 部分/漂移记录 | 覆盖字段、原始设备时间、可信采集时间 | 未覆盖或无权限不是正常结果 |

美国NHTSA查询不覆盖所有国际车辆、历史已修项目和新公布但尚未完整识别VIN的召回。对中国市场车辆，使用中国市场的合法适用性来源；没有该来源时保留未知，不据美国数据断言无召回。

本包不列高压维修流程。SRC08～11、SRC05各有特定市场/车型/日期；EV-POLICY定义安全先行与只读边界。具体DTC只有在适用官方资料和真实授权读数相符时才解释，不以公共DTC描述填造车端记录。
