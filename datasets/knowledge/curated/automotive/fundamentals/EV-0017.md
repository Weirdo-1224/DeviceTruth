# Model 3 座舱空调与电池冷却的关系

## 知识概述

空调压缩机也可用于电池冷却，炎热时即便座舱空调关闭仍可能运行。

## 适用范围与限制

厂商：Tesla；型号/系列：Model 3 (DIY generation unknown)；地区：CN；资料版本：unknown。版本未知表示原文版本未能确认，不表示任意版本适用。资料是技术解释，不是本机当前现场事实。

区分座舱命令、热管理需求和实际温度，单凭压缩机运行不能判故障。

> 注

> 除了冷却内部，空调压缩机也可冷却电池。因此，在炎热天气里，即使将其关闭，空调压缩机也可能打开。这是正常现象，因为系统优先冷却电池，以确保它保持在一个最佳温度范围，以保障较长的使用寿命和最佳的性能。此外，即使在不使用时，也可能听到 Model 3 发出呜呜声或水循环的声音。当开启内部冷却系统以支持各种车辆功能（例如维护 低压 电池和平衡高压电池温度）时会发出这些声音，属正常现象。
