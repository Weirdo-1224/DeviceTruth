# 前端工作台使用与当前状态

登录后选择个人空间或团队空间，在“继续调查”输入问题并发送。不选设备也可以进行一般知识问答。首次发送才创建调查；新调查选择的附件先在当前页面暂存，首次有效发送才创建调查、上传并等待解析，再提交分析；已有调查的附件可独立上传，不自动运行模型。

“空间成员与知识库”读取当前空间真实成员与资料。团队管理员可管理角色和邀请，协作成员可参与调查，只读成员查看结果和报告。具体权限仍由服务端每次请求裁决。

讨论区的“发表讨论”只保存讨论，不运行模型。“引用到正式补充”让原文出现在待提交列表，确认发送才进入分析；可在发送前移除。遇到调查版本冲突，保留草稿并查看最新状态，再明确提交。

调查内上传使用调查附件接口，不自动成为空间知识；解析完成后可填写名称、适用设备与条件并确认发布。SIMULATED 与未核实性质不会因为发布而升级。MD/TXT 可解析，PDF/OCR 尚未实现。

报告复用持久 Run，点击“打印 / 另存为 PDF”使用浏览器打印。打开报告不重新调用模型。

第六组6.1–6.7已完成，整体27/33；当前交付是源码与构建产物，未更新现有产品服务。隔离验收服务已停止，临时端口不能作为日常入口。实际验收、历史失败及第7/8组边界见 acceptance.md 最新记录。

口令和Session token不存浏览器存储。普通输入、讨论、补答、深入调查和引用草稿按账号/空间/调查/目标隔离；退出清理当前账号私人草稿。其他成员先处理追问时，可在“未提交的旧追问草稿”找回文字，不自动转换成新分析。
