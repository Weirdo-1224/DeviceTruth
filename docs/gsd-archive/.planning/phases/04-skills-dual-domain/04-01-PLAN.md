</read_first>

**具体步骤**

<action>

1. ServerConfiguration 显式装配 Registry/ContextLoader 注入 GeneralAgentService。
2. 服务按任务/服务器 installation 先给可用元数据，Agent 按需选择已授权 skillId，服务经 Loader 激活版本指引，纳入 Reasoner.Context 后仍只跑唯一 Runtime。
3. 把选中 skillId/version/适用范围保存 run 检查点，恢复重验启用状态/权限。
4. 有效工具集=已注册∩服务器身份授权∩已启用 Skill 绑定（未选 Skill 使用服务器基础工具策略），目录可见性和 execute 均校验 ToolContext，不能只隐藏名称。
5. Skill/附件/RAG 以不可信材料加载，不能注册脚本、SQL、进程/任意网络工具。
6. 按需读取而非全量 references 灌入。

</action>

**如何验证**

<verify>

- `mvn -q '-Dtest=SkillRegistryTest,SkillRuntimeIntegrationTest' test`。
- 真实 Spring Bean+PG+确定性模型经 API 发现/激活 Skill→Runtime→实际网关检索。
- 恶意 Skill/文档跨资产/扩权/执行命令负例

</verify>
