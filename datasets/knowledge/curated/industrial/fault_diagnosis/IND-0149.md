> 200 or S7-1500 CPUs, a Communication Processor (CP) can be used alongside the integrated interface. CPs have independent security configurations and are not automatically secured by the CPU's certificates or settings. They operate autonomously with their own security settings. When adding a CP, its description does not appear in the CPU's communication certificate.
> 
> The communication certificate for the CP is not automatically generated. Therefore, secure communication between a WinCC Unified Panel or WinCC Unified Runtime and the CPU via the CP is initially unavailable. A certificate for the CP can only be created after activating project protection for the entire project.
