Service Mode Update - Quick Touchscreen Language Switch
Servicing a vehicle set to an unfamiliar language has now become easier. When entering Service Mode, the customer's original language setting is saved. If the touchscreen language does not match the default language of the vehicle's current country location, a Change Touchscreen Language button (always shown in English) appears at the top of the Service panel and allows users to select a preferred language. Then, upon exiting Service Mode, the customer's original language setting is automatically restored. Note that touchscreen language changes trigger a restart of the user interface.

The High Voltage panel now displays status information for each isolation health dot via a popup. To view the popup, tap the health dot for the component. If the component is unhealthy, it will display the current isolation resistance values and any isolation alerts or Diagnostic Trouble Codes (DTCs) that are present on the vehicle.
