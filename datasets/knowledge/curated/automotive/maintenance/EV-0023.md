# 新款 Model 3 电池低液位告警的用户边界

## 知识概述

2024+ 手册指出电池不需车主维护，禁止自行拆冷却液罐盖或加液；低液位告警应预约服务。

## 适用范围与限制

厂商：Tesla；型号/系列：Model 3 2024+；地区：CN；资料版本：unknown。版本未知表示原文版本未能确认，不表示任意版本适用。资料是技术解释，不是本机当前现场事实。

> 法使用 Model 3 或为其充电。Model 3 长时间不充电还可能导致电池永久性损坏。如果在尝试跳线跨接启动 低压 电池后无法为 Model 3 充电，请预约服务。
> 
> 警告
> 
> 电池不需要车主维护。切勿拆卸冷却液罐盖，切勿加液。如果触摸屏发出低液位警告，请使用手机应用程序预约服务。
> 
> 警告
> 
> 请勿将电池用作固定电源，否则会使保修无效。
> 
> 如您要提供反馈，您将被重新定向到设备默认的电子邮件客户端。
