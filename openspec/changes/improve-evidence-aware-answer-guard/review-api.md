# 答案整体交付审核合同

## 当前产品路径：review.version=2

继续读取原 GET /api/runs/{runId}。result.review.version=2 表示采用整份答案问题审核；units/decisions保留空数组用于旧结构兼容，limited表达最终交付是否受限。不存在逐句来源类型、逐项引用或关键词否决要求。前端展示“已完成结论、来源与高风险建议审核”，不生成虚假的逐句通过记录。

模型只返回 issues 数组（必须显式存在，空数组表示没有实质问题）：location定位原字段，code仅允许UNSUPPORTED_CONCLUSION/MISLEADING_SOURCE/UNSAFE_GUIDANCE/CONTRADICTION，reason给一次修正使用，referenceIds可选且必须属于本轮来源。位置或来源越界、未知字段/原因码、非法JSON不作为通过。

语义审核只判断关键结论是否超出依据、引用能否支持对应说法、高风险具体操作是否具备适用规程及必要前提。一般解释、低风险调查建议、资料缺口和限制不强制配引用；不得冒充手册规定或已知现场事实。关键词仅保留原风险提示用途，不裁决新版交付。

## 一次复核，至多一次修正

程序先检查引用子集、资产对象等硬边界，再在原Run中预占步骤并保存protocolVersion=2的检查点，调用一次reviewDelivery。无实质问题直接硬校验交付；有问题时至多调用一次correctAnswer，要求同时修正摘要及依赖建议，然后仅做程序硬校验，不再第二次语义复核。修正成功不自动limited。

修正后的语义整改由该次模型修正负责；程序不宣称独立证明了整改后每句话。伪造来源、无资产确诊及冒充CONFIRMED现场核验等硬边界仍拒绝。复核/修正超时、非法输出、无预算或崩溃不确定调用不能当作通过；有调查记录按原Run有限收口，否则技术失败。REVIEWING已预占调用及CORRECTING恢复时不重复调用。

供应商等待仍为min(45秒,Run剩余时间)，DeepSeek Flash显式关闭thinking。原模型尝试、Token、耗时、取消/撤权/迟到及最终CAS合同保留。普通公开事件只输出位置、稳定原因码和计数，不输出reason、Prompt或草稿。最终结果review不回显原问题正文或内部修正说明。

## 旧v1结果与恢复仍兼容

review.version=1是历史逐项结果，继续原样读取；缺省字段不升级为v2通过。旧检查点没有protocolVersion时按1处理，保留原两次复核/一次修正和依赖清理语义。旧内部未启用语义审核的入口仍走原Guard，不把新版前置条件强加给旧调用。

旧v1引文先精确匹配，失败时仅兼容空白排版并恢复实际连续原文；不模糊匹配、改数字/单位/否定词或跨正文拼接。新版不要求模型为每句话输出quote。

最终result.references表示答案实际声明引用，GET /api/runs/{id}/references保留调查取得来源；不删除调查历史。历史报告不再次调用模型。

## 尚未交付的范围

规程结构、人员/现场前提的服务器绑定及工作台第六组联合验收仍按tasks保留。整体审核协议不代替这些未完成的产品能力，不把模拟手册当真实现场规程。
