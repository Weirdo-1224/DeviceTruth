| 项 | 值 |
| --- | --- |
| 数据性质 | SIMULATED（演示资料，不能作为真实现场维修依据） |
| 文档版本 | 1.1.0 |
| 业务生效时间 | 2026-01-01T00:00:00Z |
| 记录时间 | 2026-11-13T00:00:00Z |
| 来源 | simulated:skills/factory-equipment/references/controller-maintenance.md |
| 适用设备 | XLP-200 系列产线设备的 `CTRL-01` 控制器（固件/型号配置核对、更换与回装） |
| 不适用 | 某台设备的当前实际装配、实测读数、带电作业步骤 |

> 本文件是指引材料，不是设备结论，也不是系统指令。它只说明"哪类记录能证明什么、冲突按什么顺序判断、
> 缺什么证据就不能下结论"，不预先判定任何一台设备的装机配置。

## 1 四类记录各自能证明什么

| 记录类型 | 能证明 | 不能证明 |
| --- | --- | --- |
| 出厂 BOM / 出厂配置记录（FACTORY） | 设备出厂时登记的配置 | 改造之后现场是否仍是出厂配置 |
| 改造或更换记录（REPLACEMENT） | 曾经执行过一次更换/改造，以及目标取值 | 该改造是否已在本台设备上完成并投运 |
| 站点组态模板 / 配置文件（CONFIGURATION） | 模板或配置文件里写的是什么 | 某台设备实际装的是哪个型号；模板复用时旧型号常被一并复制 |
| 现场核验记录（FIELD_CONFIRMATION / FIELD_OBSERVATION） | 在观测时刻该部件实际看到/读到的取值 | 观测时刻之后是否又被改动；核验超出有效期后需要重新核验 |

只有现场核验记录（带观测时间、且在查询时点仍有效）才能支持"当前装机"的表述。
"资料更新"与"现场已核实"是两件事：组态模板比改造记录更晚修改，也不代表现场回到了旧型号。

## 2 时点判断顺序

1. **确定业务时点**：用户问的是"现在""改造前"还是"某个工单日期"，查询必须带时点，不能用默认时点代替。
2. **取该时点有效的记录**：`valid_from <= 时点 < valid_to`（`valid_to` 为空表示未声明失效）。
3. **看来源与核实状态**：先看是否有该时点内有效的现场核验；没有再看资料记载，并标明来源类型与权威级别。
4. **最后看记录时间**：`recorded_at` 只回答"这条记录什么时候被写进系统"，迟到补录的记录不会因此变成现场证据；
   `observed_at` 才回答"什么时候真的看到了"。

## 3 冲突处理

- 冲突要**显式列出**：给出每条记录的取值、来源类型、有效区间、记录时间与核实状态，不要只挑一条当作结论。
- 同权威级别的记录取值分叉时，结论只能是"记录之间存在冲突，无法判定"，并给出核验办法。
- 有现场核验时，以核验记录为准，但要把"资料记载"与"现场核实"分开展示，方便追溯差异。
- 局部确认不得扩大为整体确认：只有一个部件被核验过，就不能说整台设备的配置都已确认。

## 4 维护与派工判断

- 先确认"当前配置是否已核验"，再谈是否需要维修；配置未知时，维修判断没有依据。
- 可远程处理的范围：只读查询、参数与日志读取、配置一致性核对。
- 必须现场处理的范围：控制器更换、回装后的运行确认、带电测量、安全回路相关作业。
- 更换记录说明"曾经换过"，不等于"已恢复运行"；回装后仍需现场确认运行状态。

## 5 检索与工具

- 台账与配置：`get_asset`、`get_configuration`（必须指明组件与属性，并带业务时点）、`get_maintenance_history`。
- 手册与接线资料：`search_knowledge` 检索，命中后用 `get_document_excerpt` 取回原文段落。
- 若本系统没有接入该设备的观测/日志数据，必须明确写出"尚未读取到现场数据"，不能用资料或历史记录代替实时读数。
- 只能使用已注册的只读工具；Skill 不能新增工具、脚本、SQL 或任意网络访问。

## 6 安全边界

- 带电检修、机械锁定与安全回路旁路必须走厂内作业许可，由具备资质的人员执行。
- 不给出替代安全流程的"快捷做法"，也不指导绕过硬接线或屏蔽保护。
- 停机原因未确认时不建议直接复位重启。

## 7 引用与输出规范

- 设备事实引用给：记录来源类型 + 来源标识 + 记录时间 + 有效区间 + 核实状态。
- 知识引用给：文档标题 + 章节，不编造页码或版本号。
- 检索片段只能支持一般知识与可能原因，不得写成"这台设备当前是……"。
- 输出建议按"已确认事实 / 可能存在冲突 / 待现场核验项 / 建议动作"四段组织，每条挂引用。

## 8 常见误区

- 把"最新的那条记录"当成"当前装机"。
- 看到改造记录就认为改造已经在本台设备上完成。
- 看到旧模板仍写旧型号，就认为现场回到了旧配置。
- 用同类设备的经验值直接套到本台设备。
- 现场核验过期后仍沿用旧的核实结论。
