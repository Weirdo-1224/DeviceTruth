# S7-1200 用户诊断示例依赖系统内存诊断变化位

## 知识概述

V2.1示例使用DiagStatusUpdate触发诊断状态变化后的评估，因此要求使能PLC系统内存。示例中的MB地址是工程选择，不是CPU固定地址。

> 
> 2. Navigate to "System and clock memory".
> 
> 3. Enable "Enable the use of system memory byte".
