# 已确认的交互原型

用户在 2026-11-19 明确认可本设计，并授权开始 OpenSpec。`workbench.html` 为认可时的源文件快照，不是待部署前端。可直接用本地浏览器打开，或在支持该片段的对话预览中查看；无宿主图标库时装饰图标可能不显示，文字和核心交互仍可用。

## 用它确定什么

- 登录/注册/恢复、个人空间、创建和加入团队的路径。
- 空间导航、当前判断与就近补充、讨论和正式分析记录分流。
- 三角色反馈、同事运行时的草稿、同 Run 补答、取消确认。
- 调查附件与知识库显式发布、来源性质、原作者和按需证据/报告。

原型中的身份/运行由顶部“预览场景”和“结束本轮演示”切换。二者仅用于评审，不能进入正式产品。当前原型的数据保存在页面内，不使用真实认证、邮件、数据库或模型。
