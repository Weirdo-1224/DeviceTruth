## 所有计划共同遵守的执行规则

- 执行前读取用户授权范围、STATE、PROJECT、当前计划和前置计划完成记录。
- 先核对实际源码、依赖版本和当前工作树。预计路径受 Runtime 选型影响时，先同步计划。
- 按任务运行针对性验证，阶段出口检查旧离线测试与 CLI 回归。
- PG、前端、真实模型和真实 embedding 分别记录实际命令及结果。缺环境的项目记录为未验证或环境阻塞。
- 任务扩大到影响计划范围时，更新需求映射、依赖和预计文件，再继续实施。
- 完成后生成对应 SUMMARY，记录修改、测试、偏差和后续事项，再更新 STATE 与 ROADMAP。
- 用户审查和独立Review按实际情况记录。当前已完成2/13计划，独立Review最终clean，M0用户验收和阶段出口仍未关闭。
