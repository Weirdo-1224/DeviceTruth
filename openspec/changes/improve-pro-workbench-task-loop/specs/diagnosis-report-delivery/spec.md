# Spec Delta

## Purpose

将持久调查转化为可核对、可打印和可另存为 PDF 的专业报告，使用户无需再次运行模型即可交付与当前结果语义一致的调查记录。

## ADDED Requirements

### Requirement: 独立报告视图
用户 SHALL 能从专业工作台进入并退出独立报告视图。报告 MUST 直接来自持久 Run、统一排查对象、结果和已登记引用，不得为打开报告再次调用模型。

#### Scenario: 打开完成 Run 的报告
- **WHEN** 用户选择查看报告
- **THEN** 页面展示独立报告并提供返回工作台入口，不产生新的调查轮或模型调用

#### Scenario: 报告打开时回读失败
- **WHEN** 报告所需的持久数据读取失败且已有内容不足以形成报告
- **THEN** 页面显示可重试的读取失败状态，不使用其他 Run 或缓存内容拼接报告

### Requirement: 报告内容完整且语义一致
报告 SHALL 包含调查目标、实际排查对象及变更、业务时点、状态、风险、数据性质、结论、分组判断、建议、人工核验与限制、编号引用和 Run 标识。报告与工作区 MUST 使用相同判断分类和证据语义。

#### Scenario: 补答更换设备后的报告
- **WHEN** 用户在补答更换设备后打开完成报告
- **THEN** 报告显示最终排查对象及变更信息，不会继续把最初对象表述为本轮实际对象

#### Scenario: 报告包含背景观测
- **WHEN** 结果同时包含直接候选原因和背景观测
- **THEN** 报告分组呈现两者且不把背景观测写成候选故障原因

### Requirement: 报告状态与安全声明
报告 MUST 如实表达完成、进行中、待补答、失败或取消状态，并保留 SIMULATED、资料授权、未现场核验及风险处置声明。未完成状态 MUST NOT 生成虚构结论。

#### Scenario: 查看待补答报告
- **WHEN** 用户打开等待补充信息的 Run 报告
- **THEN** 报告显示当前状态和实际待答内容，不出现完成结论或伪造建议

#### Scenario: 查看模拟数据完成报告
- **WHEN** 完成结果的数据性质为 SIMULATED
- **THEN** 报告在结论和打印内容中清楚保留模拟数据及未现场核验声明

### Requirement: 引用可追溯
报告 SHALL 为实际使用及已登记的来源提供稳定编号、标题、版本、定位信息和数据性质；引用不可用或缺失时 MUST 明确表达。

#### Scenario: 打印含多个来源的报告
- **WHEN** 用户查看或打印包含多个引用的完成报告
- **THEN** 判断关联的引用编号可与报告来源清单一一对应，不显示未经授权的原文或下载地址

### Requirement: 打印与另存为 PDF
报告 SHALL 提供打印入口并支持用户使用浏览器另存为 PDF。打印输出 MUST 隐藏导航、输入及交互控件，保留报告正文、引用、风险和数据性质声明。

#### Scenario: 打印长报告
- **WHEN** 用户从浏览器打开长报告打印预览
- **THEN** 正文和来源清单按可读顺序输出，交互按钮和继续调查输入区不进入打印内容

#### Scenario: 返回工作台
- **WHEN** 用户完成打印预览或取消打印后返回报告
- **THEN** 原 Run、判断焦点和报告内容保持不变，不重新提交调查
