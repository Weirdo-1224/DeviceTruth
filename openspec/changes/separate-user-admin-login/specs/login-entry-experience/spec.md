# Spec Delta

## Purpose

提供视觉一致、身份用途明确的用户端与平台管理端登录体验，使登录者可以选择正确入口、理解账号不匹配原因，并在认证成功后回到合法业务目标，而不泄露密码或把普通登录误认为管理授权。

## ADDED Requirements

### Requirement: 两端共享视觉入口并明确切换

系统 SHALL 在登录表单提供“用户端 / 管理端”切换；`/login` 默认用户端，`/admin/login` 默认管理端。两端 SHALL 使用同一品牌、清晰标签和至少 44px 的主要操作目标，切换时标题、说明、提交按钮及当前地址保持一致。

#### Scenario: 直接打开两端登录地址
- **WHEN** 未登录访问 `/login` 或 `/admin/login`
- **THEN** 分别选中用户端或管理端，显示“登录检修工作台 / 登录平台管理端”和“登录工作台 / 登录管理端”

#### Scenario: 切换登录用途
- **WHEN** 登录者已填写邮箱和密码，再切换登录端
- **THEN** 仅在当前页面内存保留邮箱，立即清空密码、错误与旧端请求状态，切换后不会自动发起认证或授予权限

#### Scenario: 键盘和小屏幕
- **WHEN** 通过键盘或 390px 宽度屏幕使用登录页
- **THEN** 可辨识当前选项、切换入口并提交；标签和错误可被辅助技术读取，页面无整页横向溢出

### Requirement: 注册与恢复保留正确用途

用户端 SHALL 保留注册、密码恢复、重置和邀请后登录流程；管理端 MUST NOT 提供管理员自注册入口。管理账号初始设置 SHALL 使用可信维护流程，不以普通注册参数获取管理员用途。

#### Scenario: 用户注册与原邀请链接
- **WHEN** 普通用户注册，或从已有邀请/重置链接进入
- **THEN** 保留个人空间创建、邮箱绑定和单次令牌合同；登录端切换不会自动接受邀请或消费其他端令牌

#### Scenario: 管理端登录页
- **WHEN** 选择管理端
- **THEN** 不显示创建管理员账号按钮，不把注册、密码或角色参数混入管理登录请求

### Requirement: 认证后进入同端合法目标

系统 SHALL 在认证成功后自动进入对应首页或原目标页；返回地址 MUST 限制为本站、同登录端的已知路由，并由可信规则规范化。密码、会话凭据、CSRF 和重置令牌 MUST NOT 作为返回地址或切换参数传播。

#### Scenario: 管理深链接登录
- **WHEN** 未登录访问 `/admin/knowledge` 并完成管理端登录
- **THEN** 回到知识库管理页面，不强制跳转用户管理；目标空间仍由显式授权和选择决定

#### Scenario: 非法返回地址
- **WHEN** 返回目标为外域、协议相对地址、编码绕过地址、另一登录端、认证动作路径或未知路径
- **THEN** 不导航到该目标，进入当前端默认首页，不触发自动登录、退出或重置

#### Scenario: 已登录恢复
- **WHEN** 打开登录页且已有该端有效会话
- **THEN** 跳过该端登录表单，进入合法目标；仅有另一端会话时仍保留当前登录表单

### Requirement: 账号用途不匹配时显式引导

系统 SHALL 在凭据验证成功后明确说明账号用途与所选端不匹配，提供切换入口；错误密码、未知邮箱仍使用一致的认证失败结果。系统 MUST NOT 自动替换账号用途、提升角色或创建另一端会话。

#### Scenario: 用户账号尝试管理登录
- **WHEN** USER 账号以正确密码提交管理登录
- **THEN** 提示“该账号用于用户端，请切换到用户端登录”，不返回管理登录成功，不建立管理身份

#### Scenario: 管理账号尝试用户登录
- **WHEN** ADMIN 账号以正确密码提交用户登录
- **THEN** 提示“这是管理账号，请切换到管理端登录”，可保留邮箱供切换，密码清空且不自动重新提交

#### Scenario: 旧请求晚到
- **WHEN** 切换端或账号后，旧端登录、身份恢复或权限请求才返回
- **THEN** 旧结果不能导航当前页面、显示旧账号数据、清除另一端有效登录状态或覆盖新的表单状态

### Requirement: 独立退出及可恢复错误

系统 SHALL 明确退出当前登录端，保留另一端会话；登录过期、无平台权限、账号停用、网络失败与限流 SHALL 提供对应反馈，不显示虚假成功。表单中的密码 SHALL 在提交结束及切换后清空。

#### Scenario: 管理退出
- **WHEN** 两端分别登录后退出管理端
- **THEN** 管理端回到管理登录页，管理请求不能再使用该会话，用户端仍能继续读取原授权业务数据

#### Scenario: 登录服务失败
- **WHEN** 登录超时、失败或触发限流
- **THEN** 保留可更正的邮箱，清空密码，显示可读错误，不导航到未认证页面，不自动循环提交
