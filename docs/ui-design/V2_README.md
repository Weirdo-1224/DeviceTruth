# V2 原型说明

`prototype-v2.html` 是独立模拟原型，不连接真实服务、不持久化，所有调查、设备和来源均为虚构示例。直接用本机浏览器打开，或在本目录执行 `python -m http.server 8765` 后访问 `http://127.0.0.1:8765/prototype-v2.html`。右下角切换空白、进行中、已完成；也可使用 `?state=empty`、`?state=running`、`?state=complete`。选择附件不会上传，输入不会发送；历史列表为展示样例。

相比 B：进入会话后显示动态任务名及状态；调查过程区分已完成、进行中、工具、耗时和证据发现；报告分别展示资料支持、可能原因、风险、人工核验和建议；增加空工作台与运行中状态；窄屏提供导航和证据抽屉及遮罩、Escape 关闭；引用可打开来源摘录。样式统一了主色、边框、间距、焦点和按钮交互。

验证：Node 对内嵌 JavaScript 执行语法检查通过。此次尝试运行 `python -m http.server 8765 --bind 127.0.0.1`，自动化浏览器访问 `http://127.0.0.1:8765/prototype-v2.html` 超时；服务随后停止。因此没有截图，也没有声称完成浏览器渲染、交互、窄屏或无障碍验收。需要在可访问浏览器中验证 1440×900、1920×1080、375×812 的三个状态，检查滚动、溢出、抽屉、键盘焦点、引用定位和长文本。仅原型，不构成生产实现或真实诊断。
