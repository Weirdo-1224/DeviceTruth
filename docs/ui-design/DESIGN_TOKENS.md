# 原型设计 Token

适用范围：独立原型，未经可访问性对比度和多平台字体验收，不是生产设计规范。

| 类别 | 原型值 | 用途 |
|---|---|---|
| 主色 | `#5362d9` | 主操作、产品标识 |
| 文本 | `#202838`、`#536071`、`#929aa8` | 主文本、正文、辅助文字 |
| 画布 / 面板 | `#f7f8fa` / `#fff` | 工作区与内容面 |
| 边框 | `#e4e7ef` | 分隔与控件边界 |
| 提示 | `#fff8ec`、`#9a6a22` | 冲突及需核验，配文字表达 |
| 成功 | `#40a57f` | 已完成步骤，配图形及文字 |
| 字体 | Inter、Segoe UI、Microsoft YaHei、sans-serif | 系统回退；Inter 未打包 |
| 字号 | 11 / 12 / 14 / 24–28px | 标签、辅助信息、正文、标题 |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32px 为主 | 控件、区域、布局 |
| 圆角 | 5 / 7 / 9 / 11px | 标签、按钮、面板和输入 |

主按钮使用实色，次要操作低强调；焦点使用 2px 描边。风险提示保留明确文字，不依赖颜色。原型采用 1050px 和 650px 断点；窄屏右栏隐藏，目前缺少移动端证据抽屉，正式设计前必须补全并验证。模拟文件选择与追问不进行网络操作。
