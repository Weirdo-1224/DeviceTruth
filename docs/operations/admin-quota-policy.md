# 管理端配额试运行策略

用户已授权代理设计指标。此处采用小团队试运行基线 `pilot-v1`；这是资源保护阈值，不是付费套餐或供应商账单。首次部署默认未安装策略，API 返回 UNCONFIGURED；安装后在全部适配器验收前仍为 PENDING_INTEGRATION，未知用量/剩余保持 null。

| 资源 | 账号 | 空间 | 平台 | 周期 / 单位 |
| --- | ---: | ---: | ---: | --- |
| 新建 Run | 100 | 500 | 2000 | 每日 / 次 |
| 活跃 Run（含已准入队列） | 2 | 4 | 8 | 同时占用 / 条 |
| 未决 Run（含等待补答） | 10 | 40 | 100 | 同时占用 / 条 |
| 上传 | 20,000,000 | 100,000,000 | 1,000,000,000 | 每日 / 字节 |
| 导入任务 | 2 | 4 | 8 | 同时占用 / 个 |
| 检索 | 1000 | 5000 | 20000 | 每日 / 次 |
| Embedding 输入 | 500,000 | 2,000,000 | 10,000,000 | 每日 / token，需可靠计量；未知不填零 |
| SSE 连接 | 3 | 12 | 64 | 同时占用 / 条 |
| 已存储文件 | 100,000,000 | 1,000,000,000 | 10,000,000,000 | 持久占用 / 字节 |

日界线为 Asia/Shanghai 00:00，周期 `[start,end)`。所有维度同时满足才能准入；单个 Markdown 仍受原 1 MB 文件上限限制。Run 并发额度允许一定排队量，实际 worker 数仍由原有服务器配置决定。

WAITING 释放活跃槽，保留未决槽；补答不增加 Run 次数，须先重新竞争活跃槽再消费问题三元组。终态幂等释放在途占用；取消不返还已发生调用、当日上传或持久文件。重启先按资源事实对账，不清空账本后重放。

当前接入门禁：原产品同键重试仍返回 DUPLICATE_REQUEST，后续统一准入必须兼容这一409合同；文件、检索、Embedding、SSE 的全部计量与对账也必须齐备后才可宣称强制执行。`dt_quota_policy`、`dt_quota_reservation`、`dt_quota_reconciliation` 已提供持久结构，空账本不证明零消耗。

维护命令见 [管理端运维说明](platform-admin.md)。安装 `quota-pilot` 仅配置策略，不开启任何未接通的保护承诺。先在隔离库测试并观察典型使用量，再由可信维护入口调整后续版本；HTTP 不提供额度编辑、支付或套餐接口。
